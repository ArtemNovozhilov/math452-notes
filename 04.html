Functions of complex variables. Continuity and differentiability

Math 452: Complex Analysis by Artem Novozhilov©
e-mail: artem.novozhilov@ndsu.edu. Spring 2027

In this section

Let me start directly with a definition.

Definition 4.1. We say that on the set \(E\subseteq \C\) a complex function \(f\) is defined, which we will denote \[ w=f(z), \] if for any \(z\in E\) some specific (but not necessarily unique) \(w\in\C\) are assigned. We also write \[ f\colon E\longrightarrow \C \] to denote function \(f\).

Geometrically this definition means that for each point \(z\in E\) on one complex plane a mapping \(f\) is defined that assigns to specific points in \(E\subseteq \C\) point(s) \(w\) in another complex plane. Quite different from the functions of real variables in general we do not require that such point \(w=f(z)\) is unique for unique specific \(z\); it is quite natural to consider multi valued functions in complex analysis (recall the function \(\Arg z\) for instance). If, however, the complex function \(f\) is single valued, i.e., to each \(z\in E\) only one \(w\in\C\) is assigned, then the given definition of a complex function is equivalent to defining two real valued functions of two real variables (recall that the definition of a real valued function requires the output of the function to be unique): \[ (x,y)\mapsto \bigl(u(x,y),v(x,y)\bigr). \] Here we have that variables \((x,y)\) correspond to the point \(z\) from the set \(E\), and variables \((u,v)\) correspond to the coordinates of the point \(w=f(z)\) in another complex plane.

Here a curious student should be a little worried: What do we actually gain by moving from two real valued functions of two real variables to one complex function? And here is a basic answer: Complex Analysis or the Theory of Functions of Complex Variables does not in general study arbitrary mappings of one plane to another, which can be rather wild behaved and in this form belong to Real Analysis. Specifically, Complex Analysis studies much narrower class of mappings, which are called holomorphic or analytic functions. We will see precise definitions shortly, but at this point I would like to mention that such functions have a number of remarkable and inherently intertwined properties, some of which we will be studying.

Here are a few examples of functions of complex variables:

  1. A constant function \(f(z)=c\,,c\in\C\). Here \(E=\C\).

  2. A linear function \(f(z)=az+b,\,a,b\in\C\). Here \(E=\C\).

  3. A polynomial \(p(z)=c_n z^n+c_{n-1}z^{n-1}+\ldots+c_1z+c_0\) is defined clearly for all \(E=\C\). Here \(c_j\) are complex numbers.

  4. A fractional linear function \[ f(z)=\frac{az+b}{cz+d}\,,\quad a,b,c,d\in\C. \] The domain \(E\) on which this function is defined is \(E=\C\setminus\{z=-d/c\}\) (at least for now).

  5. A rational function \[ f(z)=\frac{p(z)}{q(z)}\,, \] where \(p,q\) are polynomials. This function is defined everywhere except points \(\hat z\) for which \(q(\hat z)=0\).

  6. \[ f(z)=\bar z. \] Here the relation with the real case is especially simple: \(u(x,y)=x,\,v(x,y)=-y\).

  7. \[f(z)=|z|=\sqrt{x^2+y^2}\,, \] This function is equivalent to defining two real functions \(u(x,y)=\sqrt{x^2+y^2},\,v(x,y)=0\).

  8. \[f(z)=f(x+\I y)=x+y+\I xy.\] This function is equivalent to defining two real valued functions \(u(x,y)=x+y\) and \(v(x,y)=xy\). (Can you write it in the complex variable \(z\)?)

  9. A two-valued function \[ f(z)=z^{\frac{1}{2}}=\sqrt{z}. \] Recall that any complex number, different from zero, raised to the power \(1/2\) has two complex values. Also note that, however misleading, there is a big difference (at least in these notes) when I write \(\sqrt{a}\) for positive or complex \(a\). If \(a\) is positive (and hence real) then \(\sqrt{a}=b\) is the unique positive real \(b>0\) such that \(b^2=a\) by definition. Note that there is always second real number \(-b\) which also satisfies \((-b)^2=a\), and to emphasize it, when needed, e.g., for the roots of quadratic polynomial, I write \(b=\pm \sqrt{a}\). If \(a\) is not positive and not zero then \(\sqrt{a}=a^{1/2}\) is two complex numbers. For instance, \(\sqrt{1}=1\) but \(\sqrt{-1}=\pm \I\). Some people prefer to write in this case the rational power \(\frac{1}{2}\), but it also has its own shortcomings.

  10. A multi-valued function \[ f(z)=\Arg z. \] For instance, \(f(-1)=\{\pi+2\pi k,\,k\in\Z\}\), i.e., for each complex point \(z\neq 0\) there are countably many values of this function.

I note that at this point we do not know what \(\exp z\) or \(\sin z\) actually mean, but soon we’ll get there.

For now we put aside the fact that complex functions can be multi-valued and assume that all the functions we are working with are single valued. Specifically, first I define a limit of a complex (and single) valued function when \(z\to z_0\). To be clear, I always assume that my \(f\) is defined on some open (and non-empty, I will stop mentioning this) set \(E\), and it is possible to have two possibilities: first, when \(z_0\in E\) itself (i.e., it is an interior point of the set \(E\)) or, second, when \(z_0\in\partial E\) is a boundary point of \(E\). Let us ignore the second case for now.

Definition 4.2. Let \(E\subseteq \C\) be an open set. Let \(f\colon E\longrightarrow \C\), \(z_k,z_0\in E\). We say that \[ \lim_{z\to z_0}f(z)=w, \] if for any sequence \((z_k)_{k=1}^\infty\) that converges to \(z_0\) and \(z_k\neq z_0\), the sequence \(\bigl(f(z_k)\bigr)_{k=1}^\infty\) converges to \(w\). We also denote it \[ f(z)\to w,\quad\mbox{as }z\to z_0. \]

The definition I gave is actually equivalent to the definition of a limit of a function that the students saw in Calculus I (albeit for real valued functions). If you took an introductory real analysis class, you may have seen a proof of this equivalence. Here is this second definition.

Definition 4.3. We say that \[ \lim_{z\to z_0}f(z)=w, \] if no matter how small real \(\varepsilon>0\) is chosen there always exists real \(\delta>0\) such that for all \(z\in B_\delta(z_0)\setminus\{z_0\}\) (which means \(0<|z-z_0|<\delta\)) one has \[ f(z)\in B_\varepsilon(w)\quad (\mbox{i.e., }|f(z)-w|<\varepsilon). \]

Similarly, I can introduce the limit of a function at infinity.

Exercise 1. Write down carefully a definition of the limit of a given function \(f\) when \(z\to\infty\). Do not forget the case when the limit itself is infinite.

I note that although the definitions for the limit of a function of complex variable is verbatim the same as for a function of real variable, it is much more restrictive! For a function of real variable we have only two ways to approach a point: from left or from right, whereas for a function of complex variable there are a multitude of various ways to approach the same point \(z_0\), and they all must yield the same limit.

Example 4.4. Consider \[ f(z)=f(x+\I y)=\begin{cases}0,&y=0,\\ 1,&y\neq 0. \end{cases} \] This function, considered as function of real variable (\(y=0\)) has a perfectly fine limit if \(x\to 0\), which is of course must be zero. Considered as a function of complex variable, \(f\) does not have a limit at \(z_0=0\). Indeed, let me take \[ \lim_{k\to\infty} f\left(\frac{1}{k}\right)=0, \] on the other hand \[ \lim_{k\to\infty} f\left(\frac{\I}{k}\right)=1, \] and since by approaching the zero with two different sequences I get two different answers it means that limit does not exist at \(z_0=0\).

In general the first definition of the limit of a function at a point (in terms of sequences) is nice to work with when one believes that the limit does not exist (all you need is to come up with two different sequences and show that they yield different limits). On the other hand, to prove the existence of the limit, one usually needs to use the second definition, in terms of neighborhoods. You will see some examples below.

Note that I excluded the possibility that \(z_k=z_0\). This is done to allow, at least in principle, for the value \(f(z_0)\) to be different from \(w\), or even do not exist at all. The most important case, however, is when they coincide. In this case we call \(f\) continuous at \(z_0\in E\) (again, the case how to define continuity of \(f\) on the boundary is more subtle, try to think about it).

Definition 4.5. Let \(E\subseteq \C\) be an open set. \(f\colon E\longrightarrow \C\) is called continuous at \(z_0\in E\) if \[ \lim_{z\to z_0}f(z)=f(z_0)=f\left(\lim_{z\to z_0}z\right). \] Function \(f\) is called continuous on \(E\) if it is continuous at every point of \(E\).

Example 4.6. Let \(f\colon \C\longrightarrow \C\) is defined by \(f(z)=z\). Then it is continuous on \(\C\). Here it does not matter which definition of the limit to use, since the conclusion is almost immediate. Indeed, take an arbitrary sequence \(z_k\to z_0\). I have that the sequence \(f(z_k)=z_k\to z_0\) as well, and since \(f(z_0)=z_0\) the continuity follows.

Example 4.7. Let \(f(z)=|z|\). I claim that \(f\) is continuous on \(\C\). Let me prove it using the second definition of the limit of a function. We need to show that if, for an arbitrary \(\varepsilon>0\), we are smart enough to pick \(\delta>0\) such that if \(0<|z-z_0|<\delta\) then \(|f(z)-f(z_0)|<\varepsilon\). This exactly means continuity.

Indeed, for an arbitrary \(\varepsilon>0\) take \(\delta=\varepsilon\). Then (using one of the inequalities we proved before) \[ |f(z)-f(z_0)|=\bigl||z|-|z_0|\bigr|\leq|z-z_0|<\varepsilon \] as needed and we are done.

Exercise 2. To practice the definition, prove that \(f(z)=\bar{z}\) is continuous on \(\C\).

Exercise 3. Prove that the function from Example 4.4 is not continuous.

As usual, the properties of the limits imply (almost immediately) that the sum, difference, product, and ratio of continuous functions are continuous (for the ratio the denominator cannot be zero of course). Moreover, if one is having two functions, \(f,g\), such that \(f\) is continuous at \(w_0=g(z_0)\) and \(g\) is continuous at \(z_0\) then the function composition \((f\circ g)(z_0)=f(g(z_0))\) is continuous at \(z_0\). According to the chosen philosophy of the class, I will skip the proofs of these facts.

Remark 4.8. Strictly speaking, I cannot (yet) talk about the continuity of the distance function \(d(z,w)=|z-w|\) since it is a function of two variables, and my definition works only for one variable, but it should be clear, since the distance function is a composition of very basic continuous functions, it is continuous. Remember it, very often the fact that we can push the limits inside the metric function helps with a lot of proofs.

Now to the differentiability.

Definition 4.9. Let \(E\subseteq \C\) be an open set. Function \(f\colon E\longrightarrow\C\) is called (complex) differentiable at \(z_0\in E\) if \[ \lim_{h\to 0}\frac{f(z_0+h)-f(z_0)}{h}=\lim_{z\to z_0}\frac{f(z)-f(z_0)}{z-z_0} \] exists and finite. Of course, I denote this limit \(f'(z_0)\).

Since the notion of differentiability is defined in terms of a limit, it should be clear that being complex differentiable is much more restrictive property than being real differentiable. If the reasons are unclear, keep in mind that \(h\) is a complex variable here, which can approach the origin on the complex plane in many different ways. Each such way has to lead to the same answer, only in this case the function will be differentiable at the point \(z_0\).

Example 4.10. Consider \[ f(z)=x+y+\I xy,\quad z_0=0. \] This function is not differentiable at \(z_0=0\) since, using notation \(z_0+h=z=x+\I y\) I have \[ \frac{f(z)-f(z_0)}{z-z_0}=\frac{x+y+\I xy}{x+\I y}\,, \] and the last fraction tends to 1 if \(y=0\) and to \(-\I\) if \(x=0\), therefore the sought limit does not exist.

Exercise 4. Show that the function in Example 4.10 is continuous at \(z_0=0\).

The previous example shows that a continuous function can be not differentiable at the same point. The converse is always true.

Proposition 4.11. If \(f\) is differentiable at \(z=z_0\) then it is continuous at this point.

Proof. All we need is to show that if \(f\) differentiable at \(z_0\) then \(|f(z)-f(z_0)|\to 0\) as \(z\to z_0\).

Indeed, \begin{align*} \lim_{z\to z_0}|f(z)-f(z_0)|&=\lim_{z\to z_0}|f(z)-f(z_0)|\left(\frac{|z-z_0|}{|z-z_0|}\right)=\\ &=\lim_{z\to z_0}\frac{|f(z)-f(z_0)|}{|z-z_0|}\lim_{z\to z_0}|z-z_0|=\\ &=|f'(z_0)|\cdot 0=0 \end{align*} as needed (keep track of all the properties I used in this proof). ■

While the previous proof is sleek and as elementary as possible, for the future reference let me give a different, more important theoretically, proof of the same fact.

Another proof of Proposition 4.11. First, if \(f\) is differentiable at \(z=z_0\) then \begin{equation}\label{eq4:3} f(z)=f(z_0)+f'(z_0)(z-z_0)+\phi(z,z_0)(z-z_0), \end{equation} where \(\phi(z,z_0)\to 0\) as \(z\to z_0\). Indeed, the definition of the derivative implies that \[ \left|\frac{f(z)-f(z_0)}{z-z_0}-f'(z_0)\right|<\varepsilon, \] which literally means that \[ \frac{f(z)-f(z_0)}{z-z_0}-f'(z_0)=\phi(z,z_0), \] where \(\phi(z,z_0)\to 0\) as \(z\to z_0\) since \(\varepsilon\) is arbitrarily small. Multiplying by \((z-z_0)\) leads to \(\eqref{eq4:3}\).

Now, from \(\eqref{eq4:3}\) it follows that \[ |f(z)-f(z_0)|\leq |f'(z_0)||z-z_0|+|\phi(z,z_0)||z-z_0|<\varepsilon \] since \(|f'(z_0)|\) is a constant, \(\phi\) approaches 0, and \(|z-z_0|\) can be chosen arbitrarily small. Hence \(f\) is continuous.

In addition, note that if \(\eqref{eq4:3}\) holds then \(f\) is differentiable, so it is an if and only if statement. We will need \(\eqref{eq4:3}\) later. ■

Very often the equality \(\eqref{eq4:3}\) is written as \[ f(z)=f(z_0)+f'(z_0)(z-z_0)+o(z-z_0). \] You can write the definition of \(o(z-z_0)\) (reads “o little”) by comparing the last formula with \(\eqref{eq4:3}\). This is an example of an asymptotic expression.

Since the definition of complex differentiability is verbatim the same as the definition of differentiability of a real valued function it implies that the usual rules hold. Namely,

Proposition 4.12. Assume that \(f,g\) are differentiable at \(z=z_0\) then \begin{align*} (f\pm g)'(z_0)&=f'(z_0)\pm g'(z_0),\\ (fg)'(z_0)&=f'(z_0)g(z_0)+f(z_0)g'(z_0),\\ \left(\frac{f}{g}\right)'(z_0)&=\frac{f'(z_0)g(z_0)-f(z_0)g'(z_0)}{g^2(z_0)}\,, \end{align*} and the last formula holds if \(g(z_0)\neq 0\).

Moreover, assuming that \(f\) is differentiable at \(w_0=g(z_0)\) and \(g\) is differentiable at \(z_0\) then the composition \[ h(z)=(f\circ g)(z)=f(g(z)) \] is differentiable at \(z_0\) and (chain rule) \[ h'(z_0)=f'(w_0)g'(z_0)=f'(g(z_0))g'(z_0). \]

Very often we replace our point \(z_0\) at which the derivative is taken with writing simply \(f'(z)\) or \(f'\) emphasizing that the derivative is a function of complex variable \(z\) itself.

Example 4.13. I claim that \((z^n)'=nz^{n-1}\) for any \(z\) and any integer \(n>0\). Indeed, this formula true by the definition for \(n=1\) (check it): \[ z'=1. \] Now assume that \((z^n)'=n z^{n-1}\). I have \[ (z^{n+1})'=(zz^n)'=z'z^n+nz^{n-1}z=(n+1)z^{n} \] as required. Therefore I showed that function \(z\mapsto z^n\) is differentiable for any \(z\in\C\).

Moreover, using the discussed rules and the given example, I immediately conclude that any polynomial is differentiable on all complex plane \(\C\).

Finally, the key definition of today’s lecture (and, arguably, the key definition of the whole semester, this is indeed is a big deal, try to contemplate a few seconds).

Definition 4.14. Let \(E\subseteq \C\) be an open non-empty set. Function \(f\colon E\longrightarrow \C\) is called holomorphic on \(E\) if it is differentiable at every point \(z\in E\).

Sometimes people also say that \(f\) is holomorphic at \(z=z_0\). Note that being differentiable at a point is not equivalent to be holomorphic at this point. To be holomorphic at a point means that there exists a neighborhood \(B_\varepsilon(z_0)\) such that \(f\) is differentiable at every point of this neighborhood. Being holomorphic is more restrictive, there are functions that are differentiable at a point but not holomorphic there, examples will be given in the next lecture.

One more term, which is good to remember.

Definition 4.15. A function \(f\) that is holomorphic on \(\C\) is called entire.

In the example above I showed that \(z^n\) is holomorphic on \(\C\) and hence entire. Using the rules for the derivatives of sums I conclude that any polynomial is an entire function. Any rational function is a holomorphic function on \(E\), which is the set of all points in complex plane without those at which the denominator of the rational function vanishes.

In the rest of our course we will be studying various properties of holomorphic functions. Our first task is to derive relatively simple conditions that would allow us to conclude that a function is actually holomorphic on some given \(E\).
